2. SIGN CONVENTION
------------------------------------------------------------------------------
SUBTRACTED. Line 90 is a binary minus between g and the drag term:

    acc = g - k * speed * vel

The drag term `k * speed * vel` carries no internal negative sign. With k > 0
and speed = |vel| >= 0, the subtracted vector is parallel to vel, so the net
contribution to acc is ANTIPARALLEL to vel.

------------------------------------------------------------------------------
3. GROUPING OF THE DRAG TERM
------------------------------------------------------------------------------
Literal term: k * speed * vel

    k      scalar   fit parameter (float)
    speed  scalar   np.linalg.norm(vel), line 89, the Euclidean norm |v|
    vel    VECTOR   3 components, state[3:], line 88
    g      VECTOR   3 components; the subtraction is elementwise

Grouping is (scalar k) x (scalar |v|) x (vector v), yielding a 3-vector.
Association is immaterial: (k*speed)*vel and k*(speed*vel) are elementwise
identical.

    magnitude  : |k * speed * vel| = k*|v|*|v| = k*|v|^2
                 -> QUADRATIC in speed, not linear.
    direction  : along +v, and subtracted, so the acceleration contribution is
                 -k*|v|^2 * (v/|v|), opposite the instantaneous velocity.

It is NOT a per-axis term: the only directional dependence is through the
velocity vector itself. No lift or Magnus term is present.

NO factor of 1/2, no air density, no cross-sectional area, no radius and no
mass appears anywhere in the integrand. The whole of deriv (lines 86-91) uses
only t, state, pos, vel, speed, np.linalg.norm, g, k, np.concatenate. All of
the physical grouping conventionally spread across a one-half factor, density,
area, mass and a dimensionless coefficient is absorbed into the single scalar k,
and the code never decomposes it.

Dimensional analysis of line 90. The subtraction g - k*speed*vel requires both
terms to carry the same units, so k*speed*vel must be mm/s^2:

    [k] = [acc] / ([speed]*[vel])
        = (mm/s^2) / ((mm/s) * (mm/s))
        = (mm/s^2) * (s^2/mm^2)
        = 1/mm

    K IS IN UNITS OF 1/mm  (reciprocal millimetres)

Corroborated by the repo's own labelling: drag_k_discovery.py lines 149, 277
and 424 all print or label K as "1/mm".

5.1 THE RELATION USED
---------------------
Taken from the repo's own forward formula rather than imported from outside.
src/stereo/drag_k_discovery.py lines 54-61:

    54  # K sweep centered on a physically-derived volleyball estimate:
    55  # k ~= 0.5 * rho_air * Cd * A / m, rho_air=1.2, Cd=0.4, A=0.0346 m^2, m=0.27 kg
    56  # -> k ~ 0.0308 (1/m, SI). Units note: simulate_drag's k multiplies |v|*v with
    57  # v in mm/s, so this SI k (1/m = 1/(m/s)^2 * (m/s^2)) must be scaled: a = -k*|v|*v
    58  # with v in m/s gives a in m/s^2; converting v to mm/s (factor 1000) and a to
    59  # mm/s^2 (factor 1000) means k_mm = k_SI / 1000 to keep the same physical drag.
    60  K_SI_ESTIMATE = 0.5 * 1.2 * 0.4 * 0.0346 / 0.27  # ~0.0308 (1/m)
    61  K_MM_ESTIMATE = K_SI_ESTIMATE / 1000.0  # ~3.08e-5 (1/mm), ...

    forward   : k_SI = 0.5 * rho * Cd * A / m
    conversion: k_mm = k_SI / 1000     =>     k_SI = k_mm * 1000
    inverted  : Cd = 2 * k_SI * m / (rho * A)

NOTE: the Cd = 0.4 on line 55 is the value the K SWEEP WAS CENTRED ON - an
input the repo chose before fitting, not a measured output. The computation
below does not use it.

5.2 INPUTS

    m      = 0.270           kg     volleyball mass

5.3 ASSUMPTIONS AND THEIR SOURCES
---------------------------------
    C = 0.66 m      FIVB Official Volleyball Rules ball specification:
                    circumference 65-67 cm. Midpoint of that range taken.
    m = 0.270 kg    Same specification: mass 260-280 g. Midpoint taken.
    rho = 1.225     International Standard Atmosphere, sea level, 15 degC.
                    NOT from the ball specification - an independent
                    assumption about the air, not the ball.

    Further assumptions implicit in the relation itself:
      - Cd is defined against the PROJECTED FRONTAL area of a sphere,
        A = pi*r^2, which is orientation-independent for a sphere.
      - Cd is treated as constant over the whole speed range of the flights.
        The fitted k is a single pooled scalar, so any speed dependence of Cd
        is absorbed into that one number.
      - No lift, spin or Magnus effect - the ODE contains no such term.
      - Radius is derived from circumference, not measured independently.

5.4 THE ARITHMETIC, STEP BY STEP
--------------------------------
Step 1 - convert k to SI. k is an inverse length, so the per-metre value is
         1000x the per-millimetre value (1 mm^-1 = 1000 m^-1):

    k_SI = k_mm * 1000
         = 5.26847432e-05 * 1000
         = 0.0526847432                                          1/m

Step 2 - radius from circumference, C = 2*pi*r:

    r = C / (2*pi)
      = 0.66 / 6.283185307179586
      = 0.105042262440651                                        m

Step 3 - cross-sectional area:

    r^2 = 0.0110338768986506                                     m^2
    A   = pi * r^2
        = 3.141592653589793 * 0.0110338768986506
        = 0.0346639466054148                                     m^2

    cross-check by the identity A = C^2/(4*pi), which avoids r entirely:
    A   = 0.66^2 / (4*pi)
        = 0.4356 / 12.566370614359172
        = 0.0346639466054148                                     m^2
    difference between the two routes: ~7e-18 m^2 (floating-point round-off)

Step 4 - numerator:

    2 * k_SI * m = 2 * 0.0526847432 * 0.270
                 = 0.1053694864 * 0.270
                 = 0.028449761328                                kg/m

Step 5 - denominator:

    rho * A = 1.225 * 0.0346639466054148
            = 0.0424633345916331                                 kg/m

Step 6 - divide:

    Cd = 0.028449761328 / 0.0424633345916331
       = 0.669984154603008

Units check: numerator kg/m, denominator (kg/m^3)*(m^2) = kg/m, ratio is
dimensionless, as Cd must be.

5.5 RESULT
----------

    Cd = 0.6700     (0.669984 to six decimal places)

5.6 SENSITIVITY TO THE ASSUMPTIONS
----------------------------------
Cd scales linearly with m and inversely with rho and A:

    FIVB minimum circumference (0.65 m) and mass (0.260 kg)      Cd = 0.6652
    FIVB maximum circumference (0.67 m) and mass (0.280 kg)      Cd = 0.6742
    rho = 1.2 instead of 1.225 (the value the repo used)         Cd = 0.6839
    repo's own A = 0.0346 m^2, m = 0.27 kg, rho = 1.2            Cd = 0.6852

The full FIVB manufacturing tolerance moves the result by under 2 percent. The
choice of air density moves it by about 2 percent.
