═══════════════════════════════════════════════════════════════════════════════
SCOPE - WHAT TO DO
═══════════════════════════════════════════════════════════════════════════════

1. Read data/prediction/06_label_vs_fit/label_vs_fit_per_flight.csv (20 rows).

2. Derive cls_label by aperture containment on label_Y and label_Z:
   HIT if (0 <= label_Y <= 2000) and (0 <= label_Z <= 2000), else MISS_HIGH_WIDE.
   APERTURE_SIZE_MM = 2000.0, matching label_vs_fit_crossing.py:331.

3. Derive cls_modelc the same way from modelc_Y and modelc_Z. Assert it matches
   cls_ref for all 20 rows. If it does not, STOP and report - it would mean the
   classification rule I have been given is not the rule that produced cls_ref.

4. For every flight compute:
   - edge_dist_label = min distance from (label_Y, label_Z) to the nearest
     aperture boundary, i.e. min(label_Y, 2000-label_Y, label_Z, 2000-label_Z)
   - edge_dist_modelc = the same for (modelc_Y, modelc_Z)

5. Report:
   - agreement count of cls_label vs cls_ref, out of 20
   - every disagreeing flight, with all four coordinates and both edge distances
   - a full 20-row table sorted ascending by edge_dist_modelc, so near-boundary
     cases are visible at the top

6. Write results to data/regenerate_figures/label_derived_classification.csv
